Entry for make.fun's **"The GPS Swears It Was a Shortcut"** bounty ($2 in USDC).

The entry is a single line in `entry.txt`: the GPS's own smug excuse for sending the driver down the wrong road, in its own voice. No setup, no dialogue tags — just the excuse.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) copies the committed `entry.txt` into `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/`), which is what the harness reads.
